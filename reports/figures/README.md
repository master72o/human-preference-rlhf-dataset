# Preference Analysis Figures Directory

This directory stores visual charts generated by the preference dataset analyzer:

- `preference_distribution.png`: Bar chart of A vs B vs TIE label distribution.
- `annotator_agreement.png`: Bar chart of Fleiss' Kappa ($\kappa$) and raw agreement rate vs quality targets.
- `error_tag_frequency.png`: Grouped bar chart comparing error tags on Candidate A vs Candidate B.
